# SeamFlow project page

Static project website for **SeamFlow: Structure-Aware Flow Matching on Edge Probabilities for Artist-Like UV Unwrapping**.

The page is designed for GitHub Pages and deploys automatically from `main` through the workflow in `.github/workflows/deploy-pages.yml`.

## Local preview

```bash
python3 -m http.server 4173
```

Then open <http://127.0.0.1:4173/>.

## Before the public release

- Replace the “soon” resource pills with the final paper, code, and model links.
- Add author homepages and affiliations if desired.
